One funny line a hopeless tech-support agent says to a desperate customer —
an entry for the [make.fun bounty "Have You Tried Turning It Off?"](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

## Run

```sh
python3 main.py
```

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt`).

## The line

> Good news — I turned it off and on again and it worked perfectly on my end, so I'm closing your ticket.

The classic fix, applied to the agent's own machine instead of the
customer's — cheerfully useless, ticket closed, problem unsolved.
